## Get started in three steps

Set up your Lyceum Cloud account and execute your first code on cloud infrastructure.

### Step 1: **Create Account & Install Extension**

<AccordionGroup>
  <Accordion title="Sign up for Lyceum Cloud" icon="copy">
    1. Visit the [**Lyceum Cloud Dashboard**](https://dashboard.lyceum.technology/)
    2. Create your account using email or social login

       <Tip>
         New accounts receive starter credits for immediate testing
       </Tip>
  </Accordion>
</AccordionGroup>

### Step 2: **Configure Authentication**

<AccordionGroup>
  <Accordion title="Install VS Code Extension" icon="download">
    Click this link to open the Lyceum Cloud extension directly in VS Code, or follow these steps:

    1. Open VS Code
    2. Go to Extensions (Ctrl+Shift+X)
    3. Search for “Lyceum Cloud”
    4. Click Install on the official Lyceum Cloud extension
  </Accordion>
  <Accordion title="Update your site name and colors" icon="palette">
    For a first change, let's update the name and colors of your docs site.

    1. Open `docs.json` in your editor.
    2. Change the `"name"` field to your project name.
    3. Update the `"colors"` to match your brand.
    4. Save and see your changes instantly at `http://localhost:3000`.

    <Tip>
      Try changing the primary color to see an immediate difference!
    </Tip>
  </Accordion>
</AccordionGroup>

### Step 3: Go live

<Accordion title="Publish your docs" icon="rocket">
  1. Commit and push your changes.
  2. Your docs will update and be live in moments!
</Accordion>
